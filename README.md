# pret-flakes

Unofficial Nix flakes and derivations for [pret](https://pret.github.io/) projects.

For [pret/pokered](https://github.com/pret/pokered), see [./pokered/](./pokered). (For blue, use `nix run .#pokeblue`. For blue debug, use `nix run .#pokeblue-debug`.)

For [pret/pret-pokeheartgold](https://github.com/pret/pokeheartgold), see [./pokeheartgold](./pokeheartgold). (For silver, use `nix run .#pokesoulsilver`)

For [pret/pret-pokeplatinum](https://github.com/pret/pokeplatinum), see [./pokeplatinum](./pokeplatinum).
